# OmniAgency OS — Complete Social Media Marketing Agency CRM, ERP & Production Tracker

**Tailored for 200+ Clients & 25-Member Cross-Functional Teams**

---

## 🌟 Key Features Built-in

1. **Client CRM & Services Hub (Scalable to 200+ Clients)**
   - Pre-loaded with 210 realistic client profiles and instant search/filters.
   - Enrolled Services Tracking: Video Editing, Shooting, Posting & Scheduling, Meta Ads, AI Posts, Photos, Raw Data.
   - Per-service team assignees (Management, Editor, Shooter, AI Lead, Marketer).
   - Direct Raw Data cloud storage links (Google Drive, Dropbox, Frame.io).

2. **25-Member Team Directory across 5 Departments**
   - **Management (5)**: Neha Gupta, Karan Mehra, Priya Sharma, Rohit Verma, Ananya Roy
   - **Video Editing (5)**: Rahul Sharma, Vicky Das, Amit Sen, Pooja Rawat, Kunal Joshi
   - **AI Content Team (5)**: Sameer Khan, Divya Nair, Ayush Patel, Shreya Sen, Manisha Paul
   - **Meta Ads & SMM (5)**: Aryan Malhotra, Tanvi Singhania, Sahil Kapoor, Riya Bose, Deep Patel
   - **Shooting & Production (5)**: Vikram Rathore, Arjun Mehta, Saurabh Mishra, Simran Kaur, Chetan Vyas

3. **Master Production Tracker**
   - Multi-stage pipeline: *Raw Data Ingest -> In Progress -> Internal QC -> Client Approval Pending -> Revision Requested -> Approved -> Scheduled -> Posted*.
   - Date & Time scheduling with specific publishing time slots.
   - Revision tracking with version tags (v1, v2, Master) and client feedback logs.

4. **Client Approval Center & Dedicated Client Portal**
   - Role switcher to preview and simulate exactly what each client sees.
   - Single-click **"Approve Deliverable"** or **"Request Changes / Revision"** with timestamped feedback.
   - Direct review video/creative links (Vimeo, Drive, YouTube).

5. **Real-time Team & Client Chat System**
   - Dedicated communication channels for every client.
   - **Every message has an automatic timestamp** (`DD/MM/YYYY, HH:MM AM/PM`).
   - Clear role badges for who sent the message: `[CLIENT]`, `[MANAGEMENT]`, `[VIDEO EDITING]`, `[META ADS]`, etc.

6. **Shooting & Field Production Schedule**
   - Shoot dates, call times, wrap times, studio/location addresses, crew roster, and equipment checklists.

7. **Meta Ads & Performance Hub**
   - Daily budgets, campaign funnels, creatives review links, and live metrics (Leads, CPL, ROAS).

8. **Multi-Platform Backup & Deployment (Local, GitHub, Firebase)**
   - **Local Storage + 1-Click JSON Backup**: Download full agency database backup (`.json`) anytime or restore with one click.
   - **Firebase Ready**: Connect your free Google Firebase Firestore database in settings for live multi-device syncing.
   - **GitHub Ready**: Git repository initialized with full commit history, ready to deploy to Vercel or Netlify.

## 🌐 Deploy to GitHub & Free Cloud Hosting (Vercel)

```powershell
# 1. Create a repository on GitHub (e.g. agency-crm)
# 2. Run inside the folder:
git remote add origin https://github.com/YOUR_USERNAME/agency-crm.git
git branch -M main
git push -u origin main
```
Then simply import the repository on [Vercel](https://vercel.com/new) — it builds and goes live automatically for free!
